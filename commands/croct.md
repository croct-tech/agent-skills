# Croct helper

I can help you build with Croct. These skills are available:

- `croct-use-croct` - Concepts, which skill to use, and how to look up the live docs.
- `croct-use-cli` - `croct init`, adding slots and components, types, fallback content, `croct.json`, templates.
- `croct-integrate-sdk` - Rendering slots and evaluating queries with the JavaScript, React, Next.js, Vue, Nuxt, Hydrogen, PHP, Laravel, Symfony, and Drupal SDKs.
- `croct-model-content` - Component and slot design, schema and content definition JSON, versioning.
- `croct-cql` - Writing and debugging CQL audiences and queries.
- `croct-track-events` - Events, goals, user and session attributes, identity, first-party proxy.
- `croct-personalize-and-test` - Experiences, experiments, feature flags, playbooks, analytics.
- `croct-use-api` - Content, evaluation, event tracking, and data export HTTP APIs.
- `croct-integrate-platforms` - Storyblok, Sanity, Strapi, Shopify, VTEX, GTM, Clarity, HubSpot, firmographics, and migrations.

Just ask naturally, for example:

> "Add Croct to this project and render a hero slot"
> "Create an audience for visitors from New York on mobile"
> "Why is my slot showing the fallback content?"
